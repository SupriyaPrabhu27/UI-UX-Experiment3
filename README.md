# UI-UX-Experiment3

## Aim:
To perform heuristic evaluation on 2–3 existing apps/websites, propose design improvements, and use A/B testing to evaluate the impact of these changes on user behaviour.

## Algorithm:
1.Select 2–3 apps/websites for comparison.

2.Evaluate them using Nielsen’s heuristic principles.

3.Identify issues and propose design improvements.

4.Create Version A (original) and Version B (improved).

5.Conduct A/B testing and compare user behaviour results.
